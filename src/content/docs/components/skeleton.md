---
title: Skeleton  
description: A guide to using the skeleton component.
---

`Skeleton` is a lightweight and flexible loading placeholder component. It displays an animated pulsing block, with height and width easily customizable through utility classes, making it suitable for representing text lines, images, or entire content sections during loading states.

```vue
<template>
  <div class="bg-gray-100 animate-pulse rounded-lg"></div>
</template>
```
